## Recommended block sequence

| Block # | Qualtrics block name | Contents | Logic / notes |
| --- | --- | --- | --- |
| 0 | Consent | Agree / disagree | Disagree → End |
| 1 | Screen_Category | Purchase/consider last 12 mo; usage frequency; primary use | Flag non-buyers; keep for awareness if desired |
| 2 | Awareness_Unaided | Open unaided brand list; consideration set | **No On logo yet** |
| 3 | Awareness_Aided | Aided list including On + competitors | Randomize brand list order |
| 4 | Recognition_Logo | On logo / wordmark recognition | **Page break after unaided** (`03_08` recognition after recall) |
| 5 | Ownership_Usage | Own On? which models; repertoire brands | Branch: NPS only if Own = Yes (`01_06` / `03_08` note) |
| 6 | Assoc_Strength | A1–A5 (+ E1–E4) Strength 1–5 | Randomize association order |
| 7 | Assoc_Valence | Same associations Valence 1–5 | Same order as Strength or re-randomize consistently |
| 8 | Assoc_Uniqueness | Same associations Uniqueness 1–5 | Match inventory identity set |
| 9 | Perceived_Quality | Overall quality On vs Hoka / Nike / Asics (or respondent’s alts) | Relative PQ (`01_05`) |
| 10 | Personality | Optional Aaker facet ratings | `02_03` / `03_08` personality |
| 11 | Loyalty | Satisfaction; repurchase; preference rank; **NPS 0–10 if owner** | Loyalty pyramid + NPS |
| 12 | Demographics | Age band, gender (optional), student/non-student | Keep short |
| 13 | End | Thank you | |
