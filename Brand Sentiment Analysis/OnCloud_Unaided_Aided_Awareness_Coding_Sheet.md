# On Cloud — Unaided / Aided Awareness Coding Sheet

**Purpose:** Code survey Q4–Q6 style awareness items consistently (`03_08_Quantitative Research III.pptx`: unaided recall → consideration set → aided recall → recognition).  
**Maps to:** Brand Awareness Pyramid (`01_03_Brand Equity Components I.pptx`: Unaware → Recognition → Recall → Top of Mind).

---

## Brand name variants that count as “On”

Mark **On_Mention = 1** if any of the following appear (case-insensitive; allow minor typos):

- On  
- On Cloud / OnCloud / On-Cloud  
- On Running / OnRunning  
- CloudTec / Cloudmonster / Cloudboom / Cloudsurfer / Cloudflow / Cloudswift / Cloud 5 / Cloud 6  
- Clear misspellings: “Onclouds,” “On runing,” etc. (analyst judgment — note in Comments)

**Do not count:** generic “cloud” weather; “on” as preposition only; other brands.
