## Sketch positions (Analysis — provisional)

| Brand | Approx. quadrant | Rationale (C2C-informed) |
| --- | --- | --- |
| **On** | Lifestyle + Comfort | Highest image themes = style, fit, comfort, everyday wear; cloud feel praised; durability/price contested; lifestyle SKUs pull master brand left of pure-performance peers. |
| **Hoka** | Performance + Comfort | Frequent co-mention as max-cushion running alternative; less “suburbia lifestyle shoe” coding than On’s Cloud 5/6 talk. |
| **Nike** | Performance (mid Y) | Performance-icon co-mentions; mixed cushion/reliability talk; racing/trainer systems as POD reference. |
| **Asics** | Performance + Durability | Co-mention leader; appears in durability/value contrasts vs On (Q19 frame). |
| **Brooks** | Performance + Durability | Reliable daily-trainer consideration set with Asics. |
| **New Balance** | Mid X / mid-high Y | Mixed lifestyle + trainer credibility in running discourse. |

**Ideal-point hypotheses (unverified):** (1) serious runners may prefer Performance + Durability (Asics/Brooks zone); (2) fashion/commute buyers may prefer Lifestyle + Comfort (On’s current C2C gravity). Survey must locate respondent ideal points (`02_02`).
